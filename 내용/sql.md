# SQL

## psql
터미널 위에서 돌아가는 postgre 전용 cli 클라이언트

## psql 명령어
1. psql -U sd4 -d netfilx : psql이라는 클라이언트 프로그램을 사용하여 sd4라는 계정으로 netflix라는 데이터베이스를 연다. (psql은 postgre라는 서버를 이용한다. 둘 다 local에서 돌아감. 이 명령어는 터미널 명령어)
2. \q : 계정 로그아웃
3. \! cls : 창 비우기
4. \x : 컬럼 보기
5. \du       -- 사용자 목록 (describe users)
6. \l        -- 데이터베이스 목록
