1. 깃헙에서 강사님이 만든 파일 fork, clone한 다음 uv sync, .env 파일 작성
2. 데이터 베이스 연결 (e2e테스트 이후 커밋)
3. 챗봇 ai로 연결. chatgptluna api key 받고 사용. 내가 이 컴퓨터에서 하는 개발은 claude, 내 챗봇에서 답해주는 ai는 chatgpt
4. main.py else 부분에 RAG 구현. RAG 각각을 구성하는 place.py, prompts.py, ai.py를 클로드와 구현.  (커밋)
5. aws 를 사용하여 배포. 운영체제와 사양 직접 선택. vi에디터로 .env파일 직접 작성. ngork local에서 끄고 실행. server.sh 실행하여 .venv 폴더 생성, 봇 켜기 등등을 진행함.


# 내 질문과 답변
## server.sh에선 뭐하는거지?
- 서버 터미널에서 자동으로 여러 명령을 한 번에 실행해주는 파일. .sh는 쉘 스크립트이다.
- 내가 로컬에서 설정했던 .env 파일 생성됐는지 검사, ngrok 설정, uv 설정, 24시간 돌아가게 설정 등의 터미널 명령어를 실행
- 내가 로컬에서 했던 설정을 전부 해주진 않는다는 것에 유의. clone같은 과정이나 확인만 하는 과정도 있다. 서버에 올릴 때는 방법을 좀 다르게 한다.

- 서버에서도 여전히 main.py를 사용하는 중이다.

## tests폴더는 뭐하는 폴더일까? 클로드가 중간에 막 테스트도 하던데 이 폴더랑 연관이 있는걸까? 있다면 어떻게 연관이 되어 있는걸까?
- 테스트를 하는거다. ai가 일을 똑바로 했는지 확인하는 내용이 들어있다. 자동채점 도구가 들어있다. db가 잘 연결 되었는지, ai가 잘 연결되었는지 각각을 확인하는 항목들이 나열되어 있다.

## 그 v2, v3 설명 나와 있는 폴더는 어디에 있는걸까?
- prompts.py 파일에 있다. main함수에선 v3만 사용하고 있다. else에서 v3를 불러서 ai에게 양식에 맞는 답을 보내준다. ai에게 형식에 맞는 답변을 계속 입력해주는 A 증강 부분을 담당하고 있다.

## luch.db는 왜 vscode에서 안열릴까
- sqllite 가 바이너리 파일 형태로 데이터를 저장해서. 확장 프로그램을 깔면 볼 수 있다.

## 내일 prompts.py와 readme를 읽어봐야겠다. 각 파일이 대강이라도 무슨 기능을 하면서 이 프로그램이 완성된건지 알고 싶다.
- readme는 오늘 대략 어떤 과정을 거쳐서 프로젝트를 만들었는지 설명하고 있다. prompts.py 파일은 검색 증강 생성을 할 수 있도록 도와주는 프로그램이다. v1 v2는 검색 증강 생성이 아니며 v3가 rag중 증강 부분을 담당하고 있다(AI 입력에 형식에 맞게 넣어줌). 검색은 place.py, 생성은 ai.py가 담당한다.

## aws와 vercel의 정확한 차이
- aws는 실제로 컴퓨터를 하나 임대하는 것이고, vercel은 코드만 넣으면 여타 사항들을 다 처리해준다. 그리고 임대 자체도 gui환경이라 편하다. aws는 원룸 임대, vercel은 호텔 방이라고 생각하면 편하다.

## 인스턴스
- 컴퓨터를 칸막이로 나눠 만든 가상 컴퓨터. 내부 동작 아키도 흥미롭다.
