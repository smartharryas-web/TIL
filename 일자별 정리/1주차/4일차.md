- 챗봇 만들기(환경설정)

1. uv를 깜. uv는 파이썬을 동작하게 만드는 제반사항들을 모두 도와주는 소프트웨어다. 
2. uv의 명령어를 사용하여 파이썬 폴더를 만듦.
3. .env 파일 생성. .gitignore 에 .env 파일 넣음.
4. 텔레그램 봇파더에서 봇을 만들고 토큰을 받아 .env에 저장함.
5. main.py를 작성함. 윗 부분은 다양한 함수를 import하고 밑 부분은 입력값이 왔을 때 어떻게 동작해야할지 로직이 짜여 있음.
6. .claude, claude.md, settings.json 파일을 만듦. settings.json은 claude code라는 프로그램에게 시키는 것이다. 곧, 클로드라는 LLM이 확률적으로 따르도록 만드는 것이 아니라 claude라는 LLM을 밑에서 실행시키는 claude code라는 프로그램이 막는 것이므로 명령 실행률이 100%일 것이다.
7. uvicorn이라는 웹 서버 프로그램(소프트웨어)을 터미널에서 작동시킨다. 명령어는 uv run uvicorn main:app
8. ngrok을 컴퓨터에 깔고 새 터미널에서 ngrok config add-authtoken<내토큰> 실행 - 내 ngrok 프로그램에 토큰을 등록함.
9. ngrok http 80 --url https://dollhouse-stipulate-synopsis.ngrok-free.dev 를 8000 포트로 바꾼 다음 실행 - ngrok이라는 프로그램을 사용하여 인터넷 주소를 열어라. 그리고 8000번 포트에 있는 프로그램에게 인터넷 주소를 작성한 url로 달아주어라. (웹훅 등록)
